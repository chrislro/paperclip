<objective>
Close two service-worker issues from the 2026-04-22 review:

1. **P0-3** — `_handleFetch` currently accepts an arbitrary `message.url` and forwards any `message.headers`, including a client-supplied `Authorization`. Combined with a compromised content script this is an SSRF/CSRF primitive. Restrict the target URL to the configured `apiBaseUrl` plus an `/api/*` path, and strip any inbound `Authorization` header so the SW is the sole source of auth.

2. **P1-2** — `_handleTranscribe` returns Flask's JSON verbatim; the content-script consumer (`api-client.transcribe` → `hud.js`) checks `if (!result || !result.ok)`. The check currently works only because Flask happens to echo `ok: true`. Normalize the SW return so `ok` is always derived from `resp.ok` and callers aren't depending on the backend's payload shape.

Purpose: harden the two SW handlers the external review flagged as highest-severity correctness/security. These fixes are small and self-contained in one file.
Output: updated `background/service-worker.js` with URL allowlist, stripped Auth, and normalized transcribe return shape.
</objective>

  <action>
In `_handleTranscribe` (currently around lines 207-246), the final `return resp.json()` returns Flask's JSON directly. Wrap it:

```js
if (!resp.ok) {
  const text = await resp.text().catch(() => '');
  throw new Error('HTTP ' + resp.status + ': ' + text);
}
const json = await resp.json();
return { ok: resp.ok, ...json };
```

Rationale: callers expect `result.ok` to reliably signal success. Spreading `json` after `ok: resp.ok` means a Flask response that legitimately carries a field called `ok` will still override it (`{ok: resp.ok, ok: false}` → last-write-wins). If that's ever ambiguous, the safer form is `return { ...json, ok: resp.ok }` (SW-authoritative). Use the SW-authoritative form — `{ ...json, ok: resp.ok }` — so the `ok` field in the returned object always reflects HTTP status.

Do NOT change the retry-on-network-error logic (the `await _maybeDiscoverApiUrl(true)` + second `_post()`) — that stays as-is.
  </action>
