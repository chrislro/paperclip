<objective>
Add `tocafichadr-*` entries to the Mac Mini's `automation.keychain-db` for every
existing `pedbot-*` secret, with identical values. Verifies both names resolve
to the same value before any code change is made. The old `pedbot-*` entries
remain in place as a safety net until 04-04 removes them.

Entries to rekey (per the `KEYCHAIN_SECRETS` map in `backend/keychain_helper.py`):

  pedbot-secret-key                  → tocafichadr-secret-key
  pedbot-database-url                → tocafichadr-database-url
  pedbot-stripe-secret-key           → tocafichadr-stripe-secret-key
  pedbot-stripe-webhook-secret       → tocafichadr-stripe-webhook-secret
  pedbot-stripe-pro-price-id         → tocafichadr-stripe-pro-price-id
  pedbot-stripe-hospital-price-id    → tocafichadr-stripe-hospital-price-id
  pedbot-clerk-secret-key            → tocafichadr-clerk-secret-key

Plus the additional pedbot-clerk-webhook-secret if present (referenced in
backend/emr_automation/dashboard/routes_clerk.py).
</objective>

<task type="manual">
  <name>Task 1: Rekey on the Mac Mini</name>
  <action>
SSH to the Mini and run:

```bash
set -e
KC=/Users/christianoliveira/Library/Keychains/automation.keychain-db
security unlock-keychain -p "" "$KC"

for OLD in pedbot-secret-key pedbot-database-url \
           pedbot-stripe-secret-key pedbot-stripe-webhook-secret \
           pedbot-stripe-pro-price-id pedbot-stripe-hospital-price-id \
           pedbot-clerk-secret-key pedbot-clerk-webhook-secret; do
  VAL=$(security find-generic-password -s "$OLD" -a admin -w "$KC" 2>/dev/null || true)
  if [ -z "$VAL" ]; then
    echo "SKIP $OLD (not present in keychain)"
    continue
  fi
  NEW="${OLD/pedbot-/tocafichadr-}"
  security add-generic-password -U -a admin -s "$NEW" -w "$VAL" "$KC"
  echo "REKEYED $OLD -> $NEW"
done
```
  </action>
  <verify>
For each rekeyed name, both lookups must return the same value:

```bash
for OLD in pedbot-secret-key pedbot-database-url pedbot-clerk-secret-key; do
  NEW="${OLD/pedbot-/tocafichadr-}"
  if [ "$(security find-generic-password -s "$OLD" -w "$KC" 2>/dev/null)" = \
       "$(security find-generic-password -s "$NEW" -w "$KC" 2>/dev/null)" ]; then
    echo "OK  $OLD == $NEW"
  else
    echo "FAIL mismatch on $NEW"
  fi
done
```
  </verify>
  <acceptance_criteria>
    - At least 7 entries rekeyed.
    - Each pedbot-*/tocafichadr-* pair returns the same value.
    - No old entries deleted yet.
  </acceptance_criteria>
</task>
