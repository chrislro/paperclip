<objective>
Add the sign-in gate UI in the side panel and popup. When the doctor has no
Clerk session, the side panel renders only a "Faça login" CTA + a one-line
explanation. The receita section, atestado drawer, action buttons, voice
scribe, finalize bar, and template editor are all hidden.

The mechanism is purely CSS-driven via a `body[data-authed="true"]` attribute
toggled by a small auth-state observer at the top of the side-panel JS. No
JS conditionals scattered throughout — one source of truth.

Service-worker side: SIDEPANEL_* requests that need server-side config
(SIDEPANEL_RUN_TEMPLATE, SIDEPANEL_RUN_SIMPLES_WITH_BODY, etc.) reject early
with `{ok:false, error:"sign in required"}` if `chrome.storage.local.authToken`
is absent. Pure DOM actions (SIDEPANEL_OPEN_PRESCRIPTION, SIDEPANEL_OPEN_BAU_MEDICO)
also become gated since the user can't see those buttons anyway when signed out.
</objective>
