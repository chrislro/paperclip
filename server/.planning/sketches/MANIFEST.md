# Sketch Manifest

## Design Direction

Toca Ficha Dr. is a Chrome extension that automates the G-Hosp EMR workflow for Brazilian pediatricians. Sketches explore visual directions for the marketing landing at tocafichadr.com.br — balancing clinical trust (the product touches prontuário/medical records and sits under CFM 2.454/2026) with the urgency of the core claim ("35 ações → 4, 40 min de volta"). The current landing reads as "web3 luxury SaaS" and signals the wrong industry.

## Reference Points

- Stripe, Linear — clinical restraint (A)
- NEJM, The Economist, Kinfolk — editorial authority (B)
- Bloomberg Terminal, Vercel, Resend — data-forward speed (C)
- Vercel ship week, Readme.so — kinetic typography (D)
- Apple Vision, Arc browser, Rauno Freiberg — ambient aurora (E)
- Linear changelog live demos, Cursor landing — self-playing product (F)
