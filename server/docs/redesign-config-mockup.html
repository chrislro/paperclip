Regra de ouro: como funciona o auto-preenchimento

✓ Deixe em branco para usar a dose calculada automaticamente pelo peso do paciente.
Campo no templateSe você digitar algoSe deixar em branco
Dose Usa o que você digitou OVERRIDE Catálogo /api/dosages/full?weight=XX → ex: "12 gotas (1mL)"
Frequência Usa o que você digitou OVERRIDE Catálogo → ex: "6/6h" ou "12/12h"
Duração Usa o que você digitou OVERRIDE Catálogo → ex: "7 dias"
💡 O catálogo sabe o peso do paciente. Quando você clica no botão da receita, o backend calcula a dose exata para aquele peso. Cada medicação no template recebe sua própria dose.
