Smart Templates — auto-dose prescriptions
Existing Receita Modelos extended with med-list bodies that auto-calculate per patient
v3.4.0 proposal · 2026-05-07
What changes: existing prescription templates (Resfriado, GEA, OMA, ITU, Asma, …) gain a new optional structured body that holds a list of medications. At apply time, the script computes each med's dose using the patient's weight (pediatric) or returns the fixed dose (adult), then renders a complete prescription text — ready to inject into G-Hosp's #modo_usar.
  • Backwards compatible: templates with a free-text body keep working as today (no auto-dose). Templates with a meds array get the new auto-dose path.
  • Editor: popup gains a "+ Adicionar medicação" button next to each template. Picking a med opens the catalog (12 pediatric + 20 adult). Doctor sets frequency + duration + optional notes per med.
  • Apply: click the template button → script reads patient weight from G-Hosp DOM → computes dose for each med via cached /api/dosages/full?weight=X → renders text → injects into the Simples flow.
  • Catalog: 12 pediatric meds already in backend. Adult meds need a new ADULT_MEDICATIONS list (~20 outpatient drugs).
  • Variables: in addition to meds, the body can include placeholders like ${weight}, ${age}, ${patient_name} for the extra-text area (orientações, retorno, etc.).
Schema evolution — backwards-compatible

Today (legacy, still works)

{
  id: 't_resfriado_pe',
  diagnosis: "Resfriado",
  ageBand: ">6m e <2a",
  body: "Soro fisiológico nasal 6/6h\nDipirona 1 gota/kg 6/6h se febre\nOrientar hidratação...",
  frequency: 12
}

v3.4.0 (smart, opt-in)

{
  id: 't_resfriado_pe',
  diagnosis: "Resfriado",
  ageBand: ">6m e <2a",
  meds: [
    { medId: 'dipyrone', freq: '6/6h', when: 'se febre' },
    { medId: 'paracetamol', freq: '6/6h', when: 'se dor' },
  ],
  extraText: "Soro fisiológico nasal 6/6h\nOrientar hidratação...",
  body: "..."
  frequency: 12
}

Migration is doctor-driven: existing templates stay legacy until edited. The editor offers a one-click "Converter para automático" that parses the legacy body for known med names and proposes a meds list (the doctor confirms each).
